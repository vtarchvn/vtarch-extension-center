# Đóng góp cho VTARCH Extension Center

1. Tạo Issue trước với thay đổi lớn.
2. Fork repository, tạo nhánh riêng và giữ thay đổi tập trung.
3. Không dùng `exit`, không sửa `$LOAD_PATH` hoặc biến môi trường trong plugin SketchUp.
4. Kiểm tra với SketchUp 2021+ và mô tả cách kiểm thử trong Pull Request.
5. Không gửi plugin nhị phân, thông tin đăng nhập hoặc dữ liệu riêng tư.

Mọi Pull Request cần nêu rõ tác động lên file `.rb`, `.rbz`, backup và hành vi sau khi khởi động lại SketchUp.
